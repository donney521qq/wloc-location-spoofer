# 使用、验证与恢复

## 切换定位

1. 确认 Shadowrocket VPN 已连接，WLOC 模块已启用。
2. 打开 Apple 地图并搜索目标地址。
3. 长按地图放置标记，或打开目标地点卡片。
4. 点击共享按钮。
5. 在共享菜单中选择 `WLOC设置位置`。
6. 等待快捷指令完成并显示成功结果。
7. 打开 `设置 -> 隐私与安全性 -> 定位服务`。
8. 关闭定位服务，确认关闭后再重新开启。
9. 完全退出并重新打开地图、天气和目标 App。

不要直接在快捷指令 App 中运行设置卡片来代替地图共享。没有地图共享输入时，快捷指令可能拿不到目标地点。

## 验证是否成功

至少使用两项证据：

1. 主屏幕天气组件显示目标城市，并带当前位置箭头。
2. 天气 App 顶部显示“我的位置 + 目标城市”。
3. Apple 地图点击当前位置按钮后回到目标区域。
4. Shadowrocket 日志出现 `[wloc-settings] 已保存` 和 `[wloc] 目标坐标`。

地图上的搜索结果、红色图钉或地点卡片不代表定位已修改。应检查“当前位置”或蓝点。

## 切换到另一个地址

重复“地图选点 -> 共享 -> WLOC设置位置 -> 重启定位服务”即可。每次保存会覆盖上一组坐标。

## 恢复真实定位

1. 运行 `WLOC恢复定位`。
2. 关闭并重新开启 iPhone 定位服务。
3. 完全退出并重新打开地图、天气和目标 App。
4. 确认天气的“我的位置”和地图蓝点回到真实位置。

如果恢复快捷指令不能运行，可先停用 WLOC 模块，再重新开关定位服务。

## 诊断接口

正常用户不需要手动使用以下接口。排障时，在模块已启用且 HTTPS 解密正常的前提下，可在 iPhone Safari 打开：

```text
https://gs-loc.apple.com/wloc-settings/save?action=query
```

成功时会返回当前保存的经纬度。不要把个人地址或坐标提交到公开 issue。
